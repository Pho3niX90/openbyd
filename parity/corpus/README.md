# Sample payload corpus

This corpus holds realistic BYD API payloads, one JSON file per pyBYD model (`VehicleRealtimeData.json`, `GpsInfo.json` and so on), for benchmarks and parity tests. The payloads were copied from pyBYD's tests and reference notes at the commit recorded in `parity/UPSTREAM_COMMIT`, and `VehicleRealtimeData.json` also has one synthetic payload that sets every field. All identifiers are synthetic: VINs are `TESTVIN0000000001` or `TESTVIN0000000002`, coordinates are `52.0` and `4.0`, e-mail is `user@example.com`, and tokens are strings of `X`. Each file is a JSON list of objects with the keys `source` (the upstream file the payload came from), `note` (what it shows) and `payload` (the raw input the model is validated from), indented with one space and UTF-8 encoded. `python/tests/test_corpus.py` checks that every payload validates against its model and that no identifying values remain.
